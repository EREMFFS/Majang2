# 麻雀2 追加変更 — ジャックポット金牌／子役まとめ翻

このパックは既存ゲームへの追加変更。通常牌v002、既存キャラ、画面、ルール、追加済みの役を維持して組み込む。音の追加は不要。

## 依頼文
このパックの docs/追加仕様.md と data/rule_patch.json に従って、ジャックポット対象牌の金色表示と子役の翻換算を実装してください。
金色素材は assets/jackpot/ 内。通常牌を丸ごと置き換えず、対象牌のときだけ金色版を選びます。提示欄と自分の手牌で同じ金色画像を使ってください。
子役の個別点数を廃止し、排他解決後の獲得子役４個ごとに１翻、最大４翻へ変換してください。獲得子役の一覧・根拠牌・戦歴・図鑑・子役王の集計は残してください。
reference/ は純粋関数の参考実装と境界テストです。既存エンジンの構造に合わせて移植し、受入確認.md の項目を確認してください。ゲーム本体の最新ソースはこのパックには含まれていません。

## 変更の要点
- ０〜３個＝０翻、４〜７個＝１翻、８〜11個＝２翻、12〜15個＝３翻、16個以上＝４翻。
- 子役を１個ずつ個別加点する旧処理を止める。通常の翻役と合算する。
- 完成形の手なら、子役まとめが１翻以上で和了役として使える扱いとする。
- 四面子一雀頭等の完成形、フリテン、リーチ制限等の合法性は従来どおり。
- ジャックポット100万点や役満の固定精算に、換算翻分の点数を別途足さない。
- 振込マンは旧データではclass=fixedだが表示分類は小役。100点を廃止し、子役１個へ変更する。役満など小役以外の固定点は維持。
- 旧roles.json全体で最新の役データを上書きしない。class=minorと表示分類「小役／子役」が対象。条件や追加済みの役は維持する。

## 素材
標準34種類の金色版。m1..m9、p1..p9、s1..s9、z1..z7。裏面は変更しない。
通常サイズ128×176、高解像度256×352、大サイズ512×704、回転3方向を同梱。
gold_manifest.json のパスを使う。画像は透過PNG。通常牌と同じ表示枠・牌IDを使い、物理牌データには別種類として追加しない。

既存仕様の「小役を加点」「小役を翻に変換しない」「小役は和了資格にならない」という部分より、この追加仕様を優先する。
