# 麻雀2：現金精算演出・役名案パック

現在の実写調・1980年代犯罪映画風の裏社会版へ追加する素材。ゲーム本体・音声ファイルは含まない。既存の支払い計算・確定済み金額は維持する。

## 現金の移動

演出は確定済みの精算イベントを可視化するだけとする。見た目のコールバックでゲームの残高を追加変更しない。同じ精算IDを２回流さない。

例：AからBへ23,400円。Aの顔と名前の前から１万円札２枚、千円札３枚、百円玉４枚がBへ飛ぶ。出発ごとにA側表示が減り、着地ごとにB側表示が増える。表示用の残額を補間しても、最終的には確定残高へ必ず一致させる。符号を逆転させない。

通常は１件0.8〜1.4秒程度、現金１枚あたり飛行0.35〜0.5秒。約0.04〜0.08秒ずつずらして連続射出し、軌道に軽いばらつきを付ける。着地に軽い沈み込み、0.1秒程度の紙の揺れ。画面全体を派手に揺らしすぎず、紙・束の重みを中心にする。

### 金額と絵の整合

- 100万円札束は100万円の意味。10万円の支払いを、この束１つで表現しない。
- 100万円以上は `floor(amount / 1000000)` 個の100万円束と、その残額に分ける。
- １万円単位は１万円札、千円単位は千円札、百円単位は百円硬貨。今回未用意の百円未満の端数があっても金額を丸めない。数字では正確に表示し、専用の硬貨画像を捏造しない。
- 10万円超で札の数が多い場合は、複数の１万円札スプライトを重ねた扇状グループで飛ばす。100万円束に読み替えない。
- 同時に飛ばすスプライトは通常24枚程度を上限目安とし、必要なら１つの見た目グループに「×10」等の倍率ラベルを付けて代表表示する。代表額と枚数の積が実額と一致すること。
- 送金額、受取額、最終残高は省略しない。スキップでも精算済み残高へ直接表示を合わせる。

## 三人ロンとツモ

三人ロンでは、放銃者→３人への支払いを必ず全員分流す。扇状の３本の軌道で少し時間をずらすか、３件を短く順番に再生する。１件だけで終わらせない。最終的に３人和了なら、全件の精算後に局終了へ進む。

ツモはルール側が返す各支払者→和了者の精算イベントをそのまま表示。すでに和了待機中の人が支払い対象であるときも省略しない。点棒や通常麻雀の固定額を演出側で再計算しない。

役報酬や三冠王などの自己加算は、他家から奪った見せ方にしない。画面中央の賞金エリアから受賞者へ送る。実在しない支払者の残高を減らさない。

## 所持金と借用書

順位画面の札の高さは所持金の視覚的目安。上限を設け、金額の数字を常に併記する。山の高さを線形のまま無限に伸ばさない。

所持金がマイナスの場合は借用書を表示し、名前と `負債 12,000円` のような文字を中央の空欄へ描画。ハコテンによるゲーム終了を追加しない。負債増加に応じて紙を少し重ねてもよいが、１枚の借用書を特定の固定額として扱わない。

## 三冠王・ジャックポット

- 各王５万円は１万円札５枚をバラッと渡す。同着全員にそれぞれ５万円。
- 三冠王の追加10万円は１万円札10枚。各王の15万円と合わせて合計25万円であり、25万円をさらに加えない。
- ジャックポット100万円は閉ケース→開ケースを同じ位置で切り替え、軽い蓋の開く動きと金色の照明を付ける。２枚は静止状態素材なので、細密な蓋の連番として扱わない。短いクロスフェードやフラッシュでつなぐ。
- 開ケース内は10万円の薄い束10個で合計100万円。`bundle_100man.png` は別の100万円束。ケースと束を演出で両方見せても、100万円を２回加算しない。
- 大型金額は `100万円`、通常の精算は `1,000,000円` など、画面の用途に応じて使い分ける。内部整数は従来どおり。

## 音とアニメーション

音の制作は後日。`SE_BILL_FLIP`、`SE_BILL_LAND`、`SE_BILL_COUNT`、`SE_COIN`、`SE_BUNDLE_DROP`、`SE_CASE_OPEN` のイベント名だけ用意し、音がなくても動作させる。連続札音は同時発音数を制限する。

任意のひらひら・硬貨回転・光の連番は本パックに含めない。札の反転はscaleXを縮めて表裏を差し替え、わずかな上下揺れで表現可能。硬貨はscaleXと回転で表現。紙幣の画像自体を無理に変形しない。

## 役名の取り扱い

`ROLE_NAME_PROPOSALS.md` と `data/role_name_proposals.json` は★23件への提案。名前の採用後に表示名・読みだけ変更する。roleId・条件・翻数・過去の図鑑記録は維持。ユーザーが自分で指定した三捨拾・奇数好・偶数好などの名前もMDに記載。実装中の最新ゲームデータを古い役データで上書きしない。
