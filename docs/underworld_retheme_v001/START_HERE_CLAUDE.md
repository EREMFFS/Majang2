# 麻雀2：裏社会編への差し替え指示

このフォルダは、既存の麻雀2に重ねる世界観・素材・キャラクターデータの変更パックです。ゲーム本体は含みません。いま実装済みの最新ルールを維持して、以下を実装してください。古い全部入りパックの game_config.json / roles.json で上書きしないでください。

## 今回の完成形

ロゴ・音声読み込み → タイトル「麻雀2」→ **対戦組織選択** → **VS 組織名** → 東南戦 → 局結果・三冠王・最終順位 → 主人公１位なら **組織撃破** → 組織選択へ。

組織は５つ。最初からすべて選択可能。各組織の対戦相手は掲載順の３人で固定し、抽選しない。主人公は常に **麻村 雀太郎**。以前のFFSキャラと舞台をアクティブな選択肢からすべて外す。世界観は2200年だが、映像はコテコテの1980年代の犯罪映画の雰囲気。物語、会話イベント、エンディングは追加しない。全組織撃破後も組織選択に戻り、再戦できる。

１位かどうかは、三冠王などの全加算・精算後の最終順位で判断。順位が同着になる場合は現行の同点順位処理を維持する。１位のときだけ組織ID単位で撃破フラグを保存し、組織選択カードに「撃破」を重ねる。負けても以前の撃破フラグは消さない。

## 素材・データ

- `assets/portraits/`：全16人、512×512 PNG。通常の顔グラに使用。画像内に名前なし。
- `assets/portraits_320/`：同じ顔の320×320 PNG。小さい既存フレーム用。
- `assets/portraits_hd/`：768×768 JPEG。VS画面など拡大用。
- `assets/backgrounds/`：５拠点、1440×1080 WebP。4:3。JPEG版も同梱。
- `data/characters.json`：名前・年齢・画像・所属。名前表示を復活。
- `data/stage_tables.json`：組織選択用。`selection: fixed` と `characterIds` を読む。
- `data/cpu_profiles.json`：新キャラ用の仮難易度。具体数値はバランス案。
- `data/theme_patch.json`：テーマ関連だけを既存設定へマージする。対局ルールを丸ごと置換しない。
- `PREVIEW_*.jpg`：全素材の照合用一覧。

画像は文字入りの一覧を切り抜いたものではなく、１人／１背景ずつ独立して生成した実写調画像。外周の線や隣のキャラの混入はない。切り抜き透過画像ではなく、暗い背景込みの矩形顔グラ。512版をそのまま使い、髪・帽子・顎が切れる追加トリミングは避ける。画像は静止画で、表情差分や口パクは含まない。

## UIの変更

1. 「ステージセレクト」を「対戦組織選択」に変更。５つのカードに組織名・拠点名・対戦相手３人の小顔グラを表示。
2. VS画面は主人公と敵３人を表示し、中央に `VS 紅蓮組` のような文字を動的描画。顔の下に各キャラ名。名前を画像へ焼き込まない。
3. 対局中、リザルト、戦績、キャラ別勝率・対戦履歴でも新しい名前と顔を使用。
4. 所持点・獲得点・支払い・ボーナスなどの数値表示を「円」にする。内部整数の値と計算は変えない。`score` 等の内部フィールド名も維持してよい。
5. `25,000円`、`−8,000円`、`100万円`、`5万円` のように表示。ジャックポットは **100万円**。役の「１翻」「役満」、役名「多数王」などはそのまま。点数という一般ラベルは金額・獲得金額・所持金へ文脈に応じて変更。
6. 既存の「100万点」等が焼き込まれた演出画像はその文字部分を使わず、同じ演出位置に「100万円」を動的描画する。ロン・リーチ等の文字素材は再利用できる。
7. 旧キャラIDの戦績を新キャラへ付け替えない。新テーマの対戦・撃破記録は `underworld_2200` 名前空間で保存。既存の総合戦績や役図鑑は保持。旧キャラ別記録はアーカイブして、現行15人の表に混ぜない。

対局ロジック、牌画像、金色ジャックポット牌、卓UI、既存の基本演出は再利用可能。変更の中心は素材参照とキャラ・組織データ、選択画面、名前表示、通貨表示、撃破記録。

## 双鳥羽佐助の特性

`mj2_c14` **双鳥羽佐助だけ**に `yakuman_tenpai_start` を設定。旧キャラから特性をコピーしない。毎局、役満テンパイから始まる。既存の同特性エンジンを利用し、他家や山との牌総数整合、１種４枚の制限を維持する。テンパイであり配牌即和了ではない。役満の種類を固定する新仕様は追加しない。ロン・ツモ・振聴などの判定は既存ルールに従う。主人公は特殊能力なし。

## 直近のルールを維持すること

- 誰かが和了しても他家は続行。和了者は手・役を固定して待機し、ツモも打牌もしない。全員和了または山が尽きたら局終了。早く和了すれば以後の打牌による振込みを避けられる。
- **点の取り合いを有効**。ロンは放銃者から各和了者へ支払い。３人ロンも３人分を精算し、三家和による流局や頭ハネを入れない。ハコテン終了なし、負数も許容。和了待機者の後続ツモへの支払い等、最新の決定済み精算仕様を維持。
- 和了できなかったときの役報酬と三冠王は、自分への加算として現行仕様を維持。
- 子役単体への小銭加算は廃止済み。成立数4〜7＝１翻、8〜11＝２翻、12〜15＝３翻、16以上＝４翻。段階は最高１つだけを適用し重複加算しない。子役一覧・成立根拠はリザルトに残す。0〜3個は翻への変換なし。
- 変換役名：四子安／スーツーアン、八子安／パーツーアン、十二子安／シーアルツーアン、十六子安／シーリウツーアン。読みは本作の音声用呼称。
- 対局中に子役成立を逐次通知しない。通常のリーチと、役名を示す役満リーチは維持。
- ジャックポットは毎回提示される異なる14種。該当牌を手牌・提示欄とも金色にする。金額は100万円、数値1000000を変更しない。
- 三冠王：子役王・多数王・鳴きの王に各５万円、同着は全員対象。３つすべて取ると追加10万円、合計25万円。カウント方法は最新実装を維持。

## 音声

音声ファイル制作は今回なし。女性キャラも含め、リーチ・ロン・役名・開始・終了は **１人のドスの効いた男性アナウンス** を共通利用する。敵ごとの掛け合いや個別声優は追加不要。新キャラ名や組織名の音声が未収録でも、文字表示で動くようにする。

## 確認してほしい動作

５組織に各３人、主人公を含め同時４人になる／全員の名前と画像が一致／VSが選択組織名になる／佐助だけ毎局役満テンパイ／対局中・精算・三冠王・戦績の通貨が円で統一／最終１位で撃破保存、再起動後も表示／全撃破後も再戦可能／最新ルールと図鑑を維持。
