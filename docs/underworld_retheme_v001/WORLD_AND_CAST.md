# 麻雀2：世界観と出演者

## 設定資料（今回はゲーム内の物語として表示しない）

2200年、麻雀界には新たなルールが誕生していた。
新たな役と斬新なルールは過激さを増し、命のやり取りさえ、より苛烈になっていった。
それは戦う者たちの心を揺さぶり、己の財産と裏世界の覇権を懸けて戦う武術へと進化した。
それが、麻雀2である。

未来の年代設定に、映画の中にしかいないような古典的な極道たちが生きている。映像は1980年代の実写映画のような粒子感と色味。人物・組織・場所は架空。
