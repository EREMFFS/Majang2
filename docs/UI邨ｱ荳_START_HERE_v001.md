# 麻雀2：裏社会UIの枠・背景・ボタン差し替え

添付の「子役まとめ」画面を基に、既存のゲームへ実装するためのデザイン素材・実装例をまとめたパック。ゲーム本体への適用はまだ行っていない。モックアップ画像は見た目の方向性を示す資料であり、文字・牌・獲得役の正確な表示は実データから描画する。

## 目指す外観

1980年代の極道映画の実写調。黒い漆の卓、古びた真鍮の金具、深いえんじの内張り、象牙色の文字。細い金線だけで仕切った画面を、厚みのある実物の額縁・札・精算卓のようにする。全体は厳つく、情報を載せる面は暗く静かに保つ。ファンタジーの彫刻、龍、髑髏、ネオンは追加しない。

## 子役まとめのレイアウト

画面の縦横比は現行と同じ4:3を維持。下記は **960×720のUI専用論理座標案**。既存のゲーム座標を変えたくなければ、各矩形を画面幅・高さの比率で換算する。ゲームロジックや牌判定の座標まで変更しない。

|---|---|---|
|外枠|12,12,936,696|画面全体の額|
|顔グラ|44,36,104,104|既存の実写キャラ顔＋額|
|名前・所属・結果|166,44,240,96|大きい名前、所属、順位／和了状況|
|見出し札|430,38,450,60|「子役まとめ」|

|役一覧|40,160,880,300|役名／成立牌／成立条件|
|集計の補足|48,474,864,26|換算・未和了の説明など|
|最終手牌トレー|40,508,880,112|同じ牌素材を並べ、ロン・ポン等も区別|
|補助操作|40,650,180,46|必要なら「役の詳細」「戻る」|
|主操作|700,646,220,54|「次へ」|

一覧は無理に８行を小さな文字で詰め込まない。見出し行の下に約50pxの行を５行表示し、６行目以降は一覧内スクロール。役が少なければ空き領域を保つ。全件の成立役・根拠データは残す。

列の目安は役名24%、成立牌28%、成立条件48%。役名は18px前後、条件は17〜18pxの読みやすい太さ。本文をすべて極太にしない。条件は２行まで表示できる高さを確保し、選択・フォーカスで全文を見られる領域を設ける。選択した行をえんじ色で薄くハイライトし、その行の根拠牌も同じ色で縁取りする。

手牌のトレーは横幅に応じて牌の表示サイズを決める。副露や槓で枚数が増えても枠外へはみ出さない。牌画像の縦横比を変えない。ここで牌の図柄を生成し直さず、現在使っている正しい牌画像を使う。

## ボタン

「次へ」は右下の定位置に、最低220×54相当の大きさで配置。小さい矢印を右端に添え、文字と矢印はプログラム側で描く。角金具の上に文字を重ねない。通常はえんじの面と真鍮枠。hover／キーボードfocusは枠の明度が上がり、押下時は2px沈み込む。disabledは彩度・明度を抑える。`theme.css` に各状態の例を同梱。

装飾を付けても押せる面積は矩形のまま広く確保。マウスだけでなく、現在の決定キーでも進める。hover限定で説明を見せない。クリック長押しで成立判定の詳細が開く現行操作を残す場合は、下部の説明をその操作と一致させる。

## 他の画面への展開

- 組織選択：各拠点の実写背景をカードの写真部分に使い、同じ真鍮の内枠を重ねる。組織名は黒い見出し札、撃破表示はその上に動的描画。ブラウザ標準のカードやボタンの外観を残さない。
- VS：既存の顔グラ・背景に、顔の額と組織名の見出し札を共通使用。
- 対局：卓と牌の読みやすさを優先。外周と顔の枠だけを共通化し、中央の牌山や捨て牌へ厚い額を重ねない。
- 精算・順位・三冠王：暗い漆背景＋外枠＋内枠を再利用。金額は象牙色、強調する増額は控えめな金、支払いはえんじの朱色。前回作成の札束素材とも質感をそろえる。
- ダイアログ：内枠と同じ素材を９分割で伸縮。既定の青いボタンや白いダイアログを残さない。

## 実装上の注意

画像は文字を含まない背景部品。画像全体を表示内容ごと引き伸ばすのではなく、枠は角を保つ９分割、文字は実フォント、牌・顔は既存素材を使って描く。背景は１枚、枠は１領域１枚程度にして重ねすぎない。生成素材の小さな非対称・反射差は実物感として残してよいが、レイアウトやクリック範囲は正確な矩形で定義する。

モックの役数・牌の図柄・文章は制作見本。ゲームの正解データとして転記しない。役の条件、３人和了で局終了、黄金ドラ、子役の加算専用、組織レート等の最新ルールはすべて現行実装を維持する。
