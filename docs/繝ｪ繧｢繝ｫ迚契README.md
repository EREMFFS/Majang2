# 麻雀2 リアル牌・差し替えセット v001

標準34種＋裏面、計35枚。実際の牌を意識した象牙色の樹脂、厚み、彫り、塗料、緑の背面層。
画像生成で制作し、集合画像から個別の牌を切り出した。図柄をプログラムで描いたものではない。

## 差し替え
1. tiles/の同名PNGを、ゲーム側のassets/common/tiles/へ上書きする。
2. tiles_rotated/をassets/common/tiles_rotated/へ上書きする。
3. atlasで描画している場合はtiles_atlas.pngと、新しいmanifestのsourceではなく通常の配列順を使う。10列×4行、128×176。並びはm1..m9,p1..p9,s1..s9,z1..z7,back。
4. data/common_assets.jsonの牌以外（ボタン・卓・ロゴ等）は消さない。このパックのmanifestは牌専用。
5. 高精細表示にはtiles_hd/（256×352）を使用可。手牌の表示サイズや牌ID、ルールを変える必要はない。

## 対応
m1..m9: 萬子、p1..p9: 筒子、s1..s9: 索子。
z1東,z2南,z3西,z4北,z5白,z6發,z7中。backは緑の裏面。
白は無地、１索は鳥。赤５は今回の対象外（初期ゲーム設定では赤ドラなし）。

## 描画
透過PNGなので卓にそのまま重ねる。元の簡易的な牌面の文字・丸・棒を重ね描きしない。
牌本体と厚みも画像に含む。CSSやCanvasの古い牌枠が画像を覆わないようにする。
比率を保って描画。画像の読込完了を待ってから配牌表示し、ブラウザの古いキャッシュを更新する。
Canvasは表示サイズだけでなくdevicePixelRatioに応じた描画解像度も確保し、写真調の細部をつぶさない。

preview_all.jpgは緑の卓に置いた確認用一覧。atlases/は図柄修正済みの種類別一覧。
プロンプト概要: 市販の日本式麻雀牌、象牙色の樹脂、濃い彫り文字、赤青緑の塗料、緑の背面層、ほぼ正面、各９枚の３×３配置、透明背景。画像生成ツール使用。
