# 麻雀2 — 裏社会編 v032

2200年。麻雀は財産と裏世界の覇権を懸けた武術になった——。
主人公・麻村 雀太郎（あなた）が、５つの組織の幹部３人と東南戦で戦います。誰かがあがっても局は続き、残った人で山が尽きるか全員あがるまで打ちます。
和了金はプレイヤー間で授受します（ロンは放銃者が全額、ツモは親子払い。ハコテンなし）。未和了でも最後の手牌・副露・行動履歴から役を判定して報酬が入ります。金額は「円」で表示します。
BGM（東場・南場）、実況音声、牌の音が鳴ります。

## 起動手順

### Mac
1. ZIPを展開し、`MAHJONG2` フォルダの **`start.command`** をダブルクリック。
   - 初回に「開発元を確認できない」と出たら、右クリック →「開く」→「開く」。
   - それでも開けない場合はターミナルで `bash ` と入力後に start.command をドラッグして Enter。
2. ブラウザ（既定のブラウザ）が `http://127.0.0.1:8765/index.html` を開きます。
3. 終了するときはターミナルのウィンドウを閉じます。

### Windows
1. `MAHJONG2` フォルダの **`start.bat`** をダブルクリック。
2. Python があればそれを、無ければ同梱の PowerShell 簡易サーバー（`tools/serve.ps1`）を使います。
3. 終了するときは黒いウィンドウを閉じます。

### スマホで遊ぶ
1. Mac（または Windows PC）とスマホを同じ Wi-Fi につなぐ。
2. **`start_phone.command`**（Windows は `start_phone.bat`）をダブルクリック。表示された `http://192.168.x.x:8766/index.html` をスマホのブラウザで開く。
   - 初回に「受信接続を許可しますか」と出たら許可。
3. 縦持ちでもゲーム画面を90°回して横長で表示します（スマホを左に倒すと正面）。設定の「スマホ縦持ち」で「そのまま縮小」にも変更可。
4. 操作はすべてタップ（牌は２回タップで打牌）。精算の長押しスキップも使えます。メニューに「全画面表示」（Android Chrome 等、対応ブラウザのみ）。
5. ホーム画面に追加するとアドレスバー無しで遊べます。戦績はスマホのブラウザ側に別に保存されます（PCと共有したい時は設定の書き出し/読み込み）。

### サーバー無しで開く（予備）
`index.html` を直接ブラウザで開いても動きます（`js/data_bundle.js` を使用）。
ただしブラウザによってはフォントが読み込めないため、通常は上の起動方法を使ってください。

推奨ブラウザ: Chrome / Edge / Safari の最新版。画面は 720×540（4:3）をウィンドウに合わせて等比拡大します。

## 遊び方
- **LONKA ロゴ**（LONKA CORPORATE PRESENTS）: 読み込みが終わると PRESS ANY KEY。クリック・タップ・キーを1回押すと音が使えるようになり「ピッピッ」→ **タイトル**（対局開始 / つづき / 戦績 / 役図鑑 / 設定）。
- **対戦組織選択**: ５組織（紅蓮組・相模連合・愛知爆裂山・難波大場組・邪見山連盟）。カードをクリックで選択、もう一度クリックか「決定」で VS へ。相手は組織の３人で固定。
- 最終順位（三冠王の賞金まで加算した後）で１位なら、その組織を **撃破**（カードに「撃破」の判）。負けても撃破は消えません。全部撃破した後も再戦できます。
- **打牌**: 捨てる牌を２回クリック（設定で「選択＋打牌ボタン」に変更可）。ツモ直後の牌は右端に少し離して表示。
- **ツモ / リーチ / カン**: 卓下のボタン。リーチを押すと宣言できる牌だけが選べる状態になり、その牌を捨てて成立。
- **チー / ポン / カン / ロン / 見送り**: 他家の打牌で鳴き・ロンができる時だけボタンが点灯。チーの組合せが複数ならその場で選択。
- あがっても見送れます（ツモは打牌すれば見送り、ロンは「見送り」）。リーチ後は自動でツモ切り。
- 自分があがった後は残り３人の対局を早送りで見届けます。
- テンパイ中は下の枠の右に待ち牌（残り枚数・ロンした時の翻と金額・役）、イーシャンテンなら受け入れ枚数を表示。
- ３人が和了した時点でその局は終了します（最後の一人は和了できません）。
- 右上「≡ メニュー」: 対局速度・打牌方式の切替、音のミュート、中断してタイトルへ（自動保存済み、タイトルの「つづき」で再開）。
- **黄金ドラ**: ジャックポット対象（金色）の牌を種類ごとに1枚＝1翻（最大3翻）。ドラと同じ加算翻で、和了った時だけ・鳴くと無効。
- **持ち点と所持金**: 持ち点は30,000点から。所持金は 30,000点×レート から始まり、**東場終了時に所持金が0円以下なら破産でゲームオーバー**。
- **点とお金**: 対局中は点で表示。精算で 点×レート の現金をやり取りします。レートは組織ごとに 1点＝30〜500円、南場は×2、オーラスは×3（レート倍プッシュ）。順位は麻雀の結果＝持ち点で決まり、最後の「清算」で全員の残り金額（マイナスは借金）を明かして「君は生き残れたか？」を判定します。
- **三冠王**: 東南戦の最後に、子役王・多数王・鳴きの王へ各5,000点×レート（同着は全員）、３つ全部なら追加10,000点×レート。
- **精算**: すべてクリックで１場面ずつ進みます（自動では進みません。右下の「次へ ▶」か画面の空いた所をクリック）。
  - 和了者: 和了手 → 役を１つずつ「この役はこれ！」と紹介（自動で進む。使った牌が光り、他はグレー）→ 符・翻・金額と「満貫！」「倍満！」などの称え → 子役。
    役紹介の長さは `data/game_config.json` の `settlementYakuMs`（1800）/ `settlementYakumanMs`（2600）。後日ボイスの長さに合わせて調整。
  - 未和了者: 翻役と子役を「役名｜翻｜成立に使った牌｜条件」の表でまとめて表示（多い時は頁送り）。行をクリックすると、その役の根拠の牌・行動を表示。
  - ４人分が終わったら「お金の受け渡し」（誰から誰へ・いくら）をまとめて表示 →「現在の順位」（所持金の合計順。自分は▶とYOU・金色の名前）。
  - 約１秒の長押しで、その局の精算を最後の一覧まで飛ばします。飛ばしても金額・図鑑・戦績は同じです。

## 調整できる場所
- `data/game_config.json`: 局数・連荘なし・開始点・未和了の翻点表・新役満32,000点・ジャックポット100万点など（仕様の初期案）。
  - 追加キー `yakumanTenpaiStartChance`: 役満テンパイ配牌キャラ（双鳥羽佐助）が各局で役満テンパイ配牌になる確率。初期値 1.0（毎局）。
  - `tripleCrown`: 三冠王の賞金（prizeEach 50000 / sweepBonus 100000）と数え方。多数王の数え方は初期案（子役以外の獲得役の件数）。
  - 追加キー `cpuThinkMs`: CPUの考慮の間（ミリ秒）。
  - 追加キー `bootLogo`: 音声開始ロゴの画像パス。`null` の間は麻雀2ロゴで代用。従来ロゴのファイルを置いてパスを書くだけで差し替え。
- `data/roles.json`: 役の翻・点数（`value`）、排他グループ（`exclusiveGroup` / `exclusivePriority`）、適用範囲（`scope`）。
- `data/cpu_profiles.json`: CPUの強さ（`skill`）と傾向（`tendency`）。
- サーバー起動で遊ぶ場合、JSONを書き換えてブラウザを再読み込みすれば反映されます。

## 音
- 設定画面で BGM／音声（実況）／効果音（牌）の音量、対局中メニューでミュート。最初の「クリックして開始」で音が使えるようになります（ブラウザの決まり）。
- BGM はタイトル〜組織選択＝bgm05、東場は奇数ステージ＝bgm03・偶数ステージ＝bgm04、南場＝bgm02。WAV に入っていたループ点（イントロの後〜末尾）で継ぎ目なく繰り返します。ループ点は `data/audio_events.json` の `bgm[].loopStartSec / loopEndSec`。
- 音を差し替える・足すときは `data/audio_events.json` の各イベントの `"clip"` にファイルのパスを書きます（`bus` は bgm / voice / se）。子役まとめ（四子安など）の読み上げは `yaku_bundle_4/8/12/16` に入れれば鳴ります（現在は未収録）。
- ファイルが無い・読めない場合も進行は止まりません（再生を待たない作り）。
- iPhone はマナーモード（消音スイッチ）中だと音が出ません。
- `index.html` を直接開いた場合（file://）は `js/audio_embed/`（音声の埋め込み）を読み込んで同じように鳴ります。音を差し替えたら `python3 tools/build_audio_embed.py` を実行してください。Mac の Safari で直接開くと BGM が鳴らないことがあるので start.command を使ってください。
- 新しい版にしたのに前の音や画面のままの時: 前の版の黒いウィンドウ（サーバー）を閉じてから start.bat / start.command を起動。タイトル右下の版の番号で確認できます。

## テスト
- `node tests/unit.js` … ルール・検証例（verification_cases.json）・複数ロン・ジャックポット・フリテン等
- `node tests/roles_test.js` … 130役すべての判定関数（正例・負例）、通常役の和了/未和了
- `node tests/stress.js 80` … CPU同士で80試合を通して例外・牌枚数・授受の合計・三冠王込みの所持金の整合を確認
- `tests/browser_*.js` … Playwright で実ブラウザ操作（サーバー起動中に実行）

## データの保存場所
ブラウザの localStorage（同じブラウザ・同じアドレスごと）。設定画面から JSON で書き出し・読み込みできます。
`127.0.0.1:8765` で保存したデータは、ポート番号が変わると別扱いになるので注意してください。
